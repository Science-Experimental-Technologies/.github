01 About SCIX

We make room for
the next useful idea.

Science Experimental Technologies is an Indonesia-based organization working across science, engineering, computing, and emerging technologies. We build practical software and research workflows that make complex systems easier to experiment with, inspect, and improve.

Our current public software work includes AIMix, a self-hosted AI gateway for applications, agents, and developer tools. We make the implementation and project guidance available so collaborators can evaluate the work and engage with it directly.
